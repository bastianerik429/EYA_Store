Cara menemukan ID akun

  1. Buka Mobile Legends, lalu ketuk foto profil di pojok kiri atas.
  2. Cari User ID dan Zone ID. Zone ID ada di dalam tanda kurung, contoh: 12345678 (2345).
  3. Salin kedua angka itu ke halaman isi data.
